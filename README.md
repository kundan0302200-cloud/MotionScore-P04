# MotionScore — Steady-State Accuracy Predictor (P04)

MotionScore predicts a closed-loop control system's final steady-state error from response measurements. This project focuses on integral action and persistent bias rather than treating every run as a generic response-quality case.

## Features
- Generates synthetic closed-loop response data for a first-order plant with PI control.
- Extracts early-response features: initial error, early error, error integral, control effort, and proportional/integral gains.
- Trains a Random Forest regression model to predict final steady-state error.
- Evaluates with MAE and RMSE on a held-out test set.
- Includes a Streamlit dashboard for interactive predictions and plots.
- Flags likely persistent bias using a configurable error threshold.

> The included data is simulated for educational use; it is not validated against a physical system.

## Quick start

Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python train.py
streamlit run app.py
```

`train.py` writes the trained model to `models/steady_state_model.joblib` and prints held-out MAE/RMSE.

## How it works
1. Simulate PI-controlled responses with varied setpoints, plant parameters, controller gains, disturbances, and sensor noise.
2. Use only the first part of each response to compute features.
3. Train a regression model to predict the eventual signed steady-state error.
4. Display predicted error, predicted final output, and a persistent-bias indicator.

The target error is defined as:

`steady_state_error = setpoint - final_output`

A positive error means the output settles below the setpoint; a negative error means it settles above it.

## Limitations
- Synthetic data may not represent a real plant or controller.
- Persistent bias can arise from actuator saturation, disturbances, sensor calibration, model mismatch, or disabled/limited integral action.
- Integral action often removes steady-state error in a stable, unsaturated system, but it does not guarantee zero error in every practical system.
- A prediction is only meaningful if features are measured before the final settled output. The model intentionally does not use the true final output as an input feature.
